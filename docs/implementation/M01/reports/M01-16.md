## Decisões locais

- **SC-09 Resolved in favor of IDs**: Technical names now derive from opaque IDs, not slugs. `spec/unit/service_technical_name_spec.rb` was rewritten from the opposite assertion (renaming a parent now does NOT change technical_name). This Story is named owner of SC-09 resolution. References: `docs/implementation/SPEC_CONFLICTS.md` line ~100.

- **Spec rewrites documented for review**:
  1. `spec/unit/service_technical_name_spec.rb` was completely rewritten: old assertions claimed renaming a parent slug would change technical_name (opposite of SC-09); new assertions prove it does not. SC-09 resolved in favour of IDs; this Story owns that resolution.
  2. `spec/unit/swarm_executor_spec.rb` lines 295 and 305 were rewritten: old tests checked one ad-hoc label (`opanel.resource`), new tests verify the full seven-label ownership set (`com.opanel.managed`, `team_id`, `project_id`, `environment_id`, `service_id`, `desired_revision`). Required for AC1 (namespace used exactly once) and AC2 (complete label set applied).
  3. `spec/integration/swarm_executor_lab_spec.rb` adoption tests updated: now pass labels via payload to verify AC7 idempotent adoption works with the new ownership labels.

- **AC1 test scope**: The "no literal outside module" test in `spec/unit/ownership_labels_spec.rb:9-14` scopes its grep to `app/` and `lib/` only, not `spec/`. The predicate spec in `spec/unit/ownership_predicate_spec.rb` deliberately spells out `com.opanel.*` in assertions to verify wire format: a test using the module's own constants would not prove serialization works. This is correct design.

- **Rubocop suppression**: `lib/opanel/ownership.rb:140` disables the tenancy cop with inline justification. The ownership predicate is an installation-wide identity check (validates runtime resources against the ID registry regardless of team). AC5 requires nil when a row does not exist = safe "not ours" default. The suppression is correct: the rule protects product queries (filtered by team); this is an identity query (unfiltered on purpose).
