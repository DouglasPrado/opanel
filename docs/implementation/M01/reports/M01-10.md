## Decisões locais

- NodeObservation immutability enforced via code discipline and tests rather than `readonly?` (which blocks cascade deletes when Node is deleted)
- `last_seen_at` denormalized on Node for UI query efficiency; authoritative timestamp is `NodeObservation.observed_at`
- Staleness determined by `FRESH_OBSERVATION_SECONDS = 60` (same as Cluster per doc 10 §25)
- `ObserveClusterNodes` idempotent via `find_or_create_by swarm_node_id` ensuring no duplicates on concurrent calls
- Docker failures marked UNREACHABLE on cluster; last observation preserved to maintain observability
- AC11 conflict documented as SC-20: fitness function cannot be added to `lib/gates/` during running loop

AC7 logic is proven via the Command implementation in `spec/integration/node_observation_spec.rb:39` (marks disappeared nodes DOWN without deletion) and via unit tests covering the state transitions. The real-Swarm variant (a second node actually rejoining or leaving an active Swarm) awaits a lab environment that can enrol a second node on demand.
