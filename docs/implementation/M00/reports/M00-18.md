## Schema / API / Events

The template paths are a stable contract: `docs/templates/<NAME>.md`. A gate that
names a template that is not there fails.

## Decisões locais

- **The gates name the template in the failure itself.** "No acceptance mapping"
  leaves the reader to work out what to write; "Template:
  `docs/templates/STORY_REPORT.md`" does not. A spec fails if a gate names a
  template that has been moved or removed.
- **The secret scan is proved to reach the pack**, not assumed to. A Story Report
  is exactly where a credential arrives by accident — someone pastes the output of
  a command that printed one. A planted token in a report is detected, the
  allowlist is asserted not to cover `docs/implementation`, and the report never
  echoes the value.
- **The section lists are asserted, not described.** Removing a section breaks the
  spec here rather than producing an unreviewable report three Milestones later.
