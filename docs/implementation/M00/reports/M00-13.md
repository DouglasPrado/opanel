## Decisões locais

- **Several functions pass vacuously today** — there is no MCP adapter, no
  reconciler, no serializer — and that is the point. The checker has to exist
  before the code it governs, so the first file to cross a boundary is caught by
  the build rather than by a reviewer who happened to be paying attention.
- **A vacuous pass is indistinguishable from a broken rule**, so each function is
  proven by a planted violation *and* by a compliant case it must accept. Forty-
  five examples, none of them passing by refusing everything.
- **AF-02 is Tier-0.** `docker_boundaries` grants the privilege and widening it
  needs an ADR. The checkers that contain Docker patterns *because they are the
  checkers* sit in `fitness_self_referential`, a separate list that grants
  nothing — reporting the rule for stating the rule would teach people to ignore
  it.
- **AF-09 delegates to the Migration Gate** rather than restating it. Two copies
  of a rule drift.
- **AF-02, AF-06 and AF-07 require recorded human approval to waive.** They are
  security controls, not layering rules.
- **Comments never trigger a rule.** A function that fires on the line explaining
  it is a function people learn to work around.
