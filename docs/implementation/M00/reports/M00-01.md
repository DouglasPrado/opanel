## Decisões locais

- **Generated with the asset pipeline, Hotwire, Action Cable, Action Mailer,
  Active Storage, Action Text and the Solid gems skipped.** The frozen stack
  serves its UI with Vite + Inertia (M00-04) and its queue with Solid Queue
  (M00-03); generating those layers now and replacing them later would be churn,
  not a skeleton.
- **`config/credentials.yml.enc` and `config/master.key` deleted.** Opanel takes
  configuration from the environment (M00-16). An unused encrypted credentials
  file whose key sits in the workspace is exactly the workspace secret Annex H
  §3.2 forbids. The `.gitignore` rules stay as a guardrail against reintroducing
  them. `SECRET_KEY_BASE` becomes a required environment key in M00-16;
  development and test use the Rails-generated local secret.
- **`BUNDLE_PATH: vendor/bundle` versioned in `.bundle/config`.** Makes the
  dependency tree identical for a clone, for CI and for the autonomous loop
  instead of depending on the machine's system gem directory.
- **RSpec introduced here rather than in M00-07.** M00-01 declares two required
  tests and SC-03 already froze RSpec as the runner; writing them in Minitest to
  delete them two Stories later would be churn. M00-07 keeps its full scope —
  suite types, FactoryBot, real-PostgreSQL isolation, clock control, concurrency
  barriers, parallelism and CI reporters. `spec/rails_helper.rb` deliberately does
  not touch the database yet.
- **`bin/ci` and `config/ci.rb` left in place** as generated. M00-11 owns the CI
  definition and decides whether to keep the Rails runner or replace it.
