## Findings

### F-1 — The example and error pages use plain elements instead of primitives

- **Dimensão:** Reuso
- **Severidade:** Low
- **Evidência:** `app/frontend/pages/{Home,Error}.tsx` — buttons and alert regions
  are written inline with Tailwind classes.
- **Ação:** correct in ordering. The component library is imported in M00-05 and
  the Reuse Gate is evaluated against its inventory from that point on. Creating a
  Button here would be creating exactly what is about to be imported, which is the
  duplication the gate exists to prevent. Both pages already use semantic roles and
  stable test ids, so adopting a primitive later is a substitution, not a rewrite.
- **Estado:** closed

### F-2 — `HomeController` renders content that M01 will replace

- **Dimensão:** Escopo
- **Severidade:** Low
- **Evidência:** `app/controllers/home_controller.rb` sends a `platform` prop that
  models nothing.
- **Ação:** intended. The Story asks for an example page proving server props,
  local state and an error state; it is not a screen. The real app shell with
  navigation and the team switcher is `M01-06`, and nothing here anticipates it.
- **Estado:** closed

### F-3 — Daemonized `bin/rails server` can die during Vite's first autoBuild

- **Dimensão:** Operação
- **Severidade:** Low
- **Evidência:** `bin/rails server -d` followed by a request produced a dead
  process; the same server in the foreground served `200`.
- **Ação:** not a defect in the application, and not the supported path.
  `autoBuild` exists so a bare `rails server` still renders; the intended
  development flow runs the Vite dev server alongside Rails, which `bin/dev`
  delivers in M00-06. Recorded in the Story Report so the symptom is not
  rediscovered as a mystery.
- **Estado:** open, resolved by `M00-06`

### F-4 — The CSP has no nonce, so `csp_meta_tag` emits nothing useful

- **Dimensão:** Segurança
- **Severidade:** Low
- **Evidência:** `config/initializers/content_security_policy.rb` sets no
  `content_security_policy_nonce_generator`; the layout still renders
  `csp_meta_tag`.
- **Ação:** acceptable, and stricter than the nonce alternative. The panel emits no
  inline script or style in a built asset — everything comes from Vite as an
  external module — so `script-src 'self'` holds without a nonce, and adding one
  would only create a way to allow inline content later. `csp_meta_tag` is a no-op
  under this policy rather than a hazard. If a future Story genuinely needs an
  inline script, it adds the nonce generator and says why.
- **Estado:** closed
