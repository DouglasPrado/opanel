## Findings

### F-1 — `async` supervisor mode on macOS gives up per-worker isolation

- **Dimensão:** Operação / Concorrência
- **Severidade:** Medium
- **Evidência:** `bin/jobs` — Darwin selects `--mode async`, so workers are threads
  in the supervisor process instead of forked children.
- **Ação:** forced, not preferred. Solid Queue's `fork` mode segfaults inside
  libpq the moment a forked child connects, on Ruby 4.0.6 with pg 1.6.3 on
  arm64-darwin. Four strategies were tried: a numeric `host`, pg compiled from
  source against Homebrew's libpq, `OBJC_DISABLE_INITIALIZE_FORK_SAFETY=YES`, and
  `hostaddr` to bypass hostname resolution. All still crash at
  `PG::Connection.connect_start`, in a reproduction that contains no Rails and no
  Opanel code. The consequence is real — one crashed worker takes its siblings
  down and nothing replaces it — and it applies **only to macOS development**. CI
  and Linux hosts keep `fork`, which is the mode production will run.
  The reproduction is in `bin/jobs` so the next reader does not repeat the
  investigation, and the choice is overridable with
  `OPANEL_JOB_SUPERVISOR_MODE`.
- **Estado:** open, to be revisited when workers are actually deployed (M14, or an
  earlier Story if the pg/Ruby combination changes).

### F-2 — The example jobs write directly to a table instead of calling a Command

- **Dimensão:** Escopo / Arquitetura
- **Severidade:** Low
- **Evidência:** `app/jobs/example_checkpoint_job.rb` writes
  `InfrastructureCheckpoint` without going through `app/commands/`.
- **Ação:** correct for M00 and explicitly bounded. There is no Application Layer
  to hand off to — M00 implements no domain, and inventing a Command with a single
  caller to satisfy the shape would be the speculative abstraction Annex I §5.1
  forbids. The rule itself is written into `app/jobs/README.md` and asserted by a
  test, so the first real job cannot quietly copy the example's shape.
- **Estado:** closed

### F-3 — Removing Active Job's Module serializer changes framework behaviour

- **Dimensão:** Segurança / Simplicidade
- **Severidade:** Low
- **Evidência:** `config/initializers/active_job.rb`.
- **Ação:** deliberate and narrow. It removes one serializer, leaving primitives,
  symbols, times, durations, ranges, big decimals and GlobalIDs. A job that needs
  to pass a class would now fail loudly at enqueue, which is the intended
  behaviour: Annex C §16 forbids deserializing an arbitrary class, and a job
  payload is read back from a database table. Covered by two examples so the
  behaviour cannot regress silently.
- **Estado:** closed
