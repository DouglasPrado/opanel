## Findings

### F-1 — `:concurrent` examples disable transactional isolation and clean up by hand

- **Dimensão:** Concorrência
- **Severidade:** Medium
- **Evidência:** `spec/support/concurrency.rb`; the examples in
  `spec/integration/test_harness_spec.rb` under "concurrency barrier".
- **Ação:** unavoidable, and the alternative defeats the purpose. Threads cannot
  see rows another thread has not committed, so a transactional example makes the
  race impossible to reproduce — the test would pass whether or not the lock
  existed. The cost is real: a crashed example can leave rows behind. It is
  mitigated by `unique_namespace`, so a leftover row can never be mistaken for a
  fresh one or collide with another worker, and by an `after` hook that deletes by
  that namespace. The idempotent-cleanup example exists precisely because that
  hook is not guaranteed to run.
- **Estado:** closed — accepted with the mitigation named.

### F-2 — `bin/test --parallel` needs a one-time `rake parallel:prepare`

- **Dimensão:** Operação
- **Severidade:** Low
- **Evidência:** running `--parallel` on a machine without `opanel_test2..10`
  fails with a missing database rather than a useful message.
- **Ação:** `bin/setup` (M00-06) runs the preparation, which is where a
  first-time developer meets it. A better failure message from `bin/test` itself
  would be an improvement; it is not worth a conditional that runs on every
  invocation. Recorded so it is not rediscovered as a mystery.
- **Estado:** open, resolved by `M00-06`.

### F-3 — Two spec files defined the same top-level constant

- **Dimensão:** Testes
- **Severidade:** Low
- **Evidência:** `ROOT` in both `spec/architecture/repository_layout_spec.rb` and
  `spec/gates/lint_rules_spec.rb`; the second definition won and the first file's
  expectations ran against a String where a Pathname was expected.
- **Ação:** fixed by renaming to `REPOSITORY_ROOT` and `LINT_PROBE_ROOT`. Worth
  recording rather than quietly fixing: it is the exact failure random ordering
  exists to surface, it only appeared in the full suite, and it is an argument for
  preferring `let` over constants in specs. A helper that makes the repository
  root available without a constant would remove the class of bug; that is a
  small follow-up, not a blocker.
- **Estado:** closed
