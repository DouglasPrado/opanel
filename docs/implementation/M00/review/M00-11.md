## Findings

### F-1 — `rollback-known` first restated a rule that already existed

- **Dimensão:** Correção
- **Severidade:** Medium (resolved)
- **Evidência:** the first version demanded a `# migration-forward-fix:` marker on
  every changed migration, and immediately failed on two migrations that are
  simply reversible.
- **Ação:** rewritten to ask the Migration Gate about this diff's migrations and
  read its `REVERSIBILITY` violations. Two copies of a rule drift, and the
  stricter copy would have taught people to add a meaningless marker.

### F-2 — Required approvals cannot be verified locally, so the gate fails closed

- **Dimensão:** Segurança
- **Severidade:** Low
- **Evidência:** without `gh`, `required-approvals` reports that it could not
  check and exits non-zero.
- **Ação:** deliberate. Missing evidence is never read as consent. The visible
  cost is that `bin/merge-gate` is always red on a developer's machine, which is
  correct: a merge is not decided there.

### F-3 — The five negative cases are proven locally, not through a real PR

- **Dimensão:** Testes
- **Severidade:** Low
- **Evidência:** `spec/gates/ci_pipeline_spec.rb` plants each failure and runs the
  same command the workflow runs.
- **Ação:** accepted as the strongest available proof today — this repository has
  no pull request to open yet. Recorded in the Story report as something to
  confirm against GitHub's required-check mechanism on the first real PR. What is
  proven now is the part that could actually rot: that the commands fail.

### F-4 — Two fixes outside the Story's obvious surface

- **Dimensão:** Escopo
- **Severidade:** Low
- **Evidência:** `spec/policies` and `spec/contracts` created; five layout
  offences fixed in M00-13's files.
- **Ação:** both are inside the declared boundary and both are required for the
  Story's own acceptance. The missing directories made the `contract` and
  `integration` jobs die on a `LoadError`; the offences made the `static` job red
  the first time lint ran over the whole repository. Excluding either would have
  been editing a gate to make a Story pass.
