## Findings

### F-1 — The guardrail is a property of the daemon, deliberately unskippable

- **Dimensão:** Segurança
- **Severidade:** Low
- **Evidência:** `lab_daemon?` reads the node label `opanel.lab=true` that
  `bin/swarm-lab up` applied; `assert_lab!` runs before every mutation and fails
  closed when Docker is unreachable. A spec asserts no `ENV[SKIP_/FORCE_/ALLOW_]`
  exists in either file.
- **Ação:** deliberate. The autonomous workspace must never reach a real cluster
  (Annex H §12.2), and a check an environment variable can disable is not a check
  — it is a check plus a documented way around it. The cost is that pointing the
  harness at a new daemon requires running `up` there first, which is the correct
  friction.

### F-2 — Three files were added to the Tier-0 `docker_boundaries` list

- **Dimensão:** Arquitetura
- **Severidade:** Medium
- **Evidência:** `config/architecture/fitness.yml` now lists
  `lib/gates/swarm_lab.rb`, `bin/swarm-lab` and `spec/support/swarm_lab`.
- **Ação:** accepted with the reservation recorded here. AF-02 exists to keep the
  socket inside `app/executors/`, and this widens the list that grants that
  privilege — normally an ADR-level change. It is accepted because the harness is
  test-only, has no route, and is the thing that makes the executor testable at
  all. **If M01's executor Story finds itself adding a fourth entry, that is the
  point to stop and write the ADR**, because the list will have started drifting
  from "the executor" toward "whatever needs Docker".

### F-3 — The image is configurable because the registry was unreachable

- **Dimensão:** Testes
- **Severidade:** Low
- **Evidência:** `docker pull` hung during implementation; `lab.image` plus
  `OPANEL_LAB_IMAGE` let the suite run against a locally present image, and the
  `:swarm` examples skip with instructions when none is.
- **Ação:** accepted, and better than the alternative. A harness that requires
  registry access at test time fails for reasons that have nothing to do with the
  code. Both paths are exercised: 15/15 passing with `postgres:17-alpine`, and 7
  explicit pendings without.
