## Findings

### F-1 — This Story changed the CSP and the Inertia configuration, which M00-04 owns

- **Dimensão:** Escopo
- **Severidade:** Low
- **Evidência:** `config/initializers/{content_security_policy,inertia_rails}.rb`,
  `config/environments/test.rb`.
- **Ação:** correct, and the alternative would have been to ship a knowingly broken
  application. Both changes are fixes to defects this Story's harness found: React
  did not mount at all, and the component library's styles were blocked. Leaving
  them for a later Story would mean M00-04's acceptance criteria were satisfied on
  paper while the page was blank in a browser. Both are recorded in M00-04's
  pendencies as well, so the trail is not only in this Story.
- **Estado:** closed

### F-2 — `style-src 'unsafe-inline'` weakens the panel's CSP

- **Dimensão:** Segurança
- **Severidade:** Medium
- **Evidência:** `config/initializers/content_security_policy.rb`.
- **Ação:** forced by the imported component library and reasoned rather than
  convenient. Radix writes to `element.style` to position floating elements; CSP
  treats that as an inline style and a nonce cannot authorize a CSSOM mutation.
  Under `style-src 'self'` the components render wrong — which is how this was
  found. The directive that matters is `script_src`, and it stays `'self'` with no
  `unsafe-inline` and no `unsafe-eval` outside development: inline script is code
  execution, inline style is presentation. The residual risk is CSS-based
  exfiltration, which modern browsers largely close and which requires an injection
  the strict `script-src`, the escaping and the sanitization already have to
  prevent. Removing it needs a component library that never touches
  `element.style` — an upstream change, not a configuration one.
- **Estado:** open, revisit if the library stops requiring it.

### F-3 — `OPANEL_RENDER_ERROR_PAGES` makes the test environment conditional

- **Dimensão:** Operação
- **Severidade:** Low
- **Evidência:** `config/environments/test.rb`.
- **Ação:** deliberate and narrow. Request specs want full error reports, because a
  failing test should say why in the response; browser journeys want the opposite,
  because a user sees the Inertia error page. The variable is set in one place —
  Playwright's `webServer` block — and it changes exactly two settings, both named
  at the point of change. The alternative, a third Rails environment, would
  duplicate the whole test configuration to vary two lines.
- **Estado:** closed

### F-4 — Redaction cannot rewrite an archive, so it deletes it

- **Dimensão:** Segurança / Operação
- **Severidade:** Low
- **Evidência:** `bin/redact-artifacts`.
- **Ação:** intentional, and the exit code makes it loud. A trace zip cannot be
  masked in place without unpacking and repacking it; a hit therefore removes the
  artifact and fails the run, so the leak is investigated rather than shipped. The
  scan reads the archive as bytes, which catches the common case where a trace
  stores its JSON uncompressed and misses a compressed one — a real limit, and the
  reason it is a second line of defence behind not putting credentials in fixtures
  at all. Ten examples cover both branches.
- **Estado:** closed
